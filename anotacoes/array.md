# 📑 Arrays

- 📌 O que é?
<p>Array é uma estrutura que permite armazenar vários valores em uma única variável.</p>

- 🧠 Exemplo básico
```js
  const numeros = [1, 2, 3, 4]
  const nomes = ["Lucas", "Ana", "João"]
```

- 🔥 Quando usar?
1. Guardar listas
2. Trabalhar com dados
3. Repetições e loops
4. Manipular coleções

- 🧠 Dica
<p>
  
  Quase tudo em JavaScript moderno usa array:
  APIs, bancos de dados, listas, etc.
  
  <b>
    Dominar array = subir MUITO de nível 🚀
  </b>
</p>
