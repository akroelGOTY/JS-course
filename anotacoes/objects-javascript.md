# 📦 Objetos Javascript

- 📌 O que é?
<p>objeto é uma estrutura que guarda dados + comportamentos juntos.</p>
  
- 🧠 Exemplo básico

```js
  const pessoa = {
   nome: "Lucas",
   idade: 16,
   falar: function() {
       console.log("Oi!");
     }
   };
```

- 🔥 Como usar?
1. `{}` cria o objeto
2. `chave:valor ` define propriedades
3. funções dentro = métodos
4. acessa com `.` ou `[]`

- 🧠 Dica
<p>
  Ele funciona como uma "caixinha" com propriedades e funções.
</p>
